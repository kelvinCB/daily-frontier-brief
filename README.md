# Daily Frontier Brief

A responsive daily brief with five fresh stories across artificial intelligence, biotechnology,
robotics, and adjacent frontier technology.

## Daily Update

GitHub Actions runs at `10:00 UTC`, which is `6:00 AM AST`, updates `data/news.json`, commits the
new day, and lets Vercel deploy the latest static build.

## Commands

```bash
npm install
npm run news:update
npm run build
npm run dev
```
